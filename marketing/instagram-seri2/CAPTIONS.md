## 01 — Diagnosis ICD-10 & SNOMED CT

```
Mengisi kode diagnosis sering jadi bagian paling lama saat menulis rekam medis.

Di ApexRecord, bagian Assessment pada SOAP bisa dicari pakai bahasa sehari-hari. Ketik "gigi berlubang", "radang gusi", atau "darah tinggi" — kode ICD-10 yang sesuai langsung muncul, lengkap dengan padanan SNOMED CT.

• 18.500+ kode ICD-10 dan 499.000+ konsep SNOMED CT
• Bisa dicari lewat kode, nama resmi, atau istilah sehari-hari
• Untuk dokter gigi, diagnosis bisa dicatat per gigi, misalnya K02.1 · gigi 36

Biasanya Anda mencari kode diagnosis dari mana — hafalan, buku, atau Google?

Coba pencariannya langsung di apexrecord.my.id

#ApexRecord #RekamMedisElektronik #ICD10 #DokterGigi #DokterUmum
```

## 02 — Odontogram per gigi

```
Pasien datang lagi setelah 6 bulan. Gigi mana yang dulu ditambal, mana yang masih perlu perawatan?

Odontogram di ApexRecord menyatu dengan catatan SOAP dan riwayat pasien. Kondisi tiap gigi — karies, tambalan, mahkota, gigi hilang — tersimpan per kunjungan, jadi riwayatnya bisa dibaca tanpa membuka lembar lama.

Dibuat untuk praktik mandiri dokter gigi (TPMDG) sampai klinik gigi dengan beberapa dokter.

Dokter gigi di sini masih pakai odontogram kertas atau sudah digital?

#ApexRecord #Odontogram #DokterGigi #KlinikGigi #TPMDG
```

## 03 — Stok otomatis per tindakan

```
Stok bahan klinik jarang habis tiba-tiba. Biasanya pemakaiannya saja yang tidak tercatat.

Di ApexRecord, Anda cukup mengatur sekali bahan apa saja yang dipakai untuk tiap tindakan. Contoh: scaling memakai sarung tangan, masker, dan pasta profilaksis. Setiap kali tindakan itu ditagihkan, stok berkurang otomatis.

• Peringatan saat stok di bawah batas minimum
• Laporan pemakaian bahan dan nilai inventory
• Stok kembali otomatis kalau tagihannya dibatalkan

Di klinik Anda, siapa yang biasanya pertama tahu stok bahan hampir habis?

#ApexRecord #ManajemenKlinik #StokKlinik #OwnerKlinik #KlinikGigi
```

## 04 — Fee share dokter

```
Rekap fee dokter akhir bulan sering makan waktu: cocokkan tindakan, hitung persentase, cek ulang di Excel.

Di ApexRecord, fee diatur per tindakan — persentase atau nominal tetap. Selama sebulan, setiap tindakan yang dikerjakan dokter otomatis masuk ke perhitungan bagi hasilnya.

• Laporan fee per dokter per bulan, lengkap dengan rincian tindakan
• Dokter bisa melihat fee miliknya sendiri
• Bisa diekspor ke Excel untuk keperluan payroll

Transparan untuk owner, jelas untuk dokter.

Sistem bagi hasil di klinik Anda pakai persentase atau nominal tetap?

#ApexRecord #FeeDokter #ManajemenKlinik #OwnerKlinik #PraktikDokter
```

## 05 — Heatmap jam ramai (Laporan Keuangan Pro)

```
Apakah jadwal dokter di klinik Anda sudah sesuai dengan jam pasien datang?

Laporan Keuangan Pro menampilkan heatmap kunjungan per hari dan per jam, dibuat otomatis dari data kunjungan yang sudah tercatat. Dari situ terlihat jam yang terlalu padat, dan jam yang sebenarnya bisa dikurangi.

Di laporan yang sama juga ada:
• Retensi pasien — berapa persen pasien lama yang kembali
• Customer Lifetime Value dan rasio LTV:CAC
• Sebaran asal pasien per kabupaten/kota, kecamatan, dan kelurahan

Data di gambar adalah ilustrasi. Di akun Anda, angkanya dari data klinik sendiri.

#ApexRecord #LaporanKeuangan #OwnerKlinik #BisnisKlinik #ManajemenKlinik
```

## 06 — API website klinik

```
Sudah punya website klinik, tapi jadwal dokternya masih diperbarui manual?

Dengan API Website Klinik dari ApexRecord, website Anda mengambil data langsung dari sistem: profil klinik, jam buka, jadwal dan foto dokter, layanan dan tarif, sampai slot yang masih kosong.

• Pasien bisa booking dan membatalkan reservasi dari website
• Pasien cek status reservasi cukup dengan nomor WhatsApp dan nama
• API key terkunci ke domain website Anda dan tidak membuka data rekam medis

Ubah jadwal sekali di ApexRecord, website ikut menyesuaikan.

Detail teknis untuk developer website Anda ada di apexrecord.my.id

## 07 — Informed consent digital

```
Lembar informed consent itu penting, tapi menyimpan dan mencarinya kembali sering merepotkan.

## 08 — Keamanan & audit log

```
Sebagai pemilik klinik, apakah Anda tahu siapa saja yang membuka data pasien hari ini?

ApexRecord mencatat setiap akses dan perubahan data pasien di audit log: siapa, kapan, dan apa yang dilakukan. Kalau ada akses dalam jumlah tidak wajar — misalnya ratusan rekam medis dibuka dalam beberapa menit — sistem menandainya sebagai peringatan.

Lapisan keamanan lain yang aktif otomatis:
• Verifikasi dua langkah wajib untuk akun owner
• Logout atau ganti password langsung mencabut sesi lama
• Dokter, admin, dan owner hanya melihat data sesuai perannya

Data pasien adalah tanggung jawab klinik. Sistemnya sebaiknya ikut membantu menjaganya.

#ApexRecord #KeamananData #RekamMedisElektronik #OwnerKlinik #ManajemenKlinik
```
